# Board Game Design

Design educational board games that run themselves once the teacher starts them. The output is a complete kit: board layout, components, card decks, rules, narrative, and a collective ending.

## Design stance

- Start from the learning objective and the classroom gap. Every component must do a game job and an educational job at once.
- Classrooms have 20-30 students, board games seat 4-8. Choose a model up front: teams of 4-5 as one player, tournament brackets, multiple copies as stations, or one oversized cooperative board for the whole class.
- The board itself should teach. Quiz questions pasted onto a generic track is chocolate-covered broccoli.
- Prototype with cardboard, playdough and recycled materials first. The tactile prototype is part of the creative process.

## The collective ending

The strongest classroom board games do not end with one winner. Use a two-phase ending:

1. Individual phase: players compete and gather resources, cards or clues.
2. Collective phase: everyone pools what they gathered to solve a final puzzle or code together.

The final puzzle must be too complex for one student, must need resources held by different players, and must feel like the story's climax. This keeps every student engaged to the last minute and makes the final learning moment shared.

## Component notes

- **Custom dice**: replace pips with content (planets, elements, verbs). Every roll becomes incidental learning.
- **Card decks**: task cards (do something, not just answer), knowledge cards (answer for points), chance cards, special event cards that move the narrative. Include at least 20 task cards so the game survives repeated sessions.
- **Board spaces**: mix movement, challenge, bonus, mystery, QR-code spaces linking to digital clues, and physical search spaces that send players to find something in the room. Use penalty spaces sparingly.
- **Help system**: a player who helps a stuck peer earns a bonus move.
- **Roles**: give each player a unique ability others may need.

## Creative constraints

- If standard dice are a problem in your school, swap in a familiar randomizer (a salt shaker works).
- If a 40-minute period is too short, design a board with no fixed start or end. Players begin anywhere, move in any direction, and the teacher calls time.
- Limited budget and materials usually produce the better design.

## Classroom practicalities

Laminate everything. Components fit in one box or folder. Setup under 5 minutes, rules explained in under 2. Works with different group sizes and ability levels. Playtest with real students, observe without intervening, iterate, and be willing to discard the whole game if it does not work.

## Anti-patterns

- One player dominates early and the others check out. Add comeback mechanics and the collective ending.
- Teacher has to run every turn. The teacher facilitates, the game runs itself.
- More rules mistaken for more learning.
- A single fixed difficulty.

## Done when

A teacher could build the kit from the materials list, start the game in five minutes, and every student is still engaged when the collective puzzle is solved.
